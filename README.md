# SCUM Building Editor (RU) 🛠️

Профессиональный инструмент для редактирования и планирования строительных объектов в игре **SCUM**. Позволяет удобно управлять параметрами базы через графический интерфейс.

## 📖 Описание
Данное приложение предназначено для модификации и настройки элементов строительства. Оно упрощает работу с конфигурациями баз, предоставляя визуальный доступ к данным, которые обычно скрыты в файлах игры.

## ✨ Основные возможности
- **Полная локализация:** Интерфейс переведен на русский язык.
- **Управление объектами:** Редактирование стен, фундаментов, каркасов и других модулей.
- **Категоризация:** Удобная сортировка элементов по типам и материалам.
- **DPI Fix:** Поддержка корректного отображения на мониторах с высоким разрешением.
- **Быстрый запуск:** Не требует установки дополнительных библиотек (Portable EXE).

## 🚀 Запуск
Для использования готовой версии:
1. Скачайте архив из раздела [Releases](https://github.com/tolyan28rus/SCUM-Building-Editor/releases).
2. Запустите файл  `SCUM_Building_Editor.exe`.

## 🛠 Технический стек
- **Язык:** Python 3.12
- **Библиотека интерфейса:** PyQt5
- **Сборка:** PyInstaller
